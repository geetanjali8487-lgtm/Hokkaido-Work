# Hokkaido Work

Hokkaido Work is a job-search resource for international students, career restarters, and other international job seekers interested in full-time or part-time work in Hokkaido and elsewhere in Japan. It focuses on opportunities that do not require Japanese.

## Live site

[Visit Hokkaido Work](https://geetanjali8487-lgtm.github.io/Hokkaido-Work/)

## Project scope

This repository currently contains a static landing page introducing the project and its intended audience. Job listings and application tools are not live yet.
